# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/).

## [1.1.0] — 2026-10-28

### Добавлено
- **Автораспаковка загрузок.** Фоновый режим (`--watch`) со значком в трее следит за папкой «Загрузки» и сам распаковывает новые ZIP-файлы. Ждёт, пока браузер докачает файл.
- **Автозапуск** вместе с Windows (раздел `HKCU\...\Run`), запуск сразу после установки без перезагрузки.
- После успешной распаковки архив **перемещается в корзину** (в обоих режимах). Если распаковка не удалась, архив остаётся на месте, а недоделанная папка удаляется.
- Меню значка в трее: включить/выключить автораспаковку, открыть папку загрузок, выход.
- Уведомления о результате распаковки.
- Установщик умеет обновлять установленную версию.

### Изменено
- Установка и удаление теперь управляют ещё и автозапуском и настройками (`HKCU\Software\ZipHere`).
- Для работы с корзиной в сборку добавлена библиотека `Microsoft.VisualBasic.dll` (входит в .NET Framework).

## [1.0.0] — 2026-10-28

### Добавлено
- Пункт «Распаковать здесь» в контекстном меню ZIP-архивов.
- Установщик и удаление в одном `.exe` (повторный запуск предлагает удалить).
- Установка без прав администратора (раздел реестра `HKCU`).
- Окно прогресса и сообщение об ошибке при неудачной распаковке.
- Защита от перезаписи: если папка уже существует, создаётся `имя_1`, `имя_2`, …
- Сборка без сторонних зависимостей через встроенный в Windows `csc.exe`.
- GitHub Actions: автоматическая сборка и публикация релизов по тегу `v*`.
