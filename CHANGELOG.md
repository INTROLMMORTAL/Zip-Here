# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/).

   ## [1.3.0] — 2026-11-10

   ### Исправлено
   - Сообщение об ошибке распаковки показывает настоящую причину и название распаковщика, а не служебную строку `tar.exe`.

   ### Изменено
   - Для RAR используется UnRAR из WinRAR, если он установлен (раньше только 7-Zip и встроенный `tar.exe`).
   
## [1.2.0] — 2026-11-10

### Добавлено
- Поддержка **RAR, 7z, TAR, TGZ, TBZ2, TXZ, .tar.gz/.tar.bz2/.tar.xz** (помимо ZIP).
- Пункт «Распаковать здесь» теперь есть у всех этих форматов.
- Автораспаковка в «Загрузках» работает для RAR, 7z и tar-архивов.
- Формат определяется по содержимому файла, а не по расширению: «.zip», который на самом деле RAR (и наоборот), теперь распаковывается.
- Если ZIP не открывается встроенными средствами (например, нестандартное сжатие), запускается запасной распаковщик.
- Понятные сообщения: архив с паролем, вместо архива скачана веб-страница, многотомный архив.
